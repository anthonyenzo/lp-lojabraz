# Loja BrazHits

Catálogo mobile-first dos Packs BrazHits, organizado pelos gêneros:

- Sertanejo
- Sertanejo Raiz
- Forró / Arrocha
- Pagode
- Rock Nacional
- Gospel

A página é exportada como site estático e publicada em `https://brazhits.com.br/loja/` pelo GitHub Actions.

As capas e os links individuais de checkout podem ser adicionados posteriormente em `app/page.tsx`.
